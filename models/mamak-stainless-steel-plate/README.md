# Mamak Stainless Steel Plate

V2.1 backlog 377. Shallow round stainless dining plate with a real recessed bowl, rolled rim and separate underside foot ring.

Blender 4.0.2: generate.py creates source/GLB; -- --export-source preserves source edits. render_views.py renders the shipped GLB; prepare_previews.py converts WebPs. Validate with node validate.mjs. inspect_source.py and node verify_source_edit.mjs prove actual source editing.

Metres; Blender +Z / glTF +Y up; Blender -Y / glTF +Z front. Original static visual prop, not a certified food-contact appliance or cooking simulation. Physical Android/iOS not tested; public redistribution terms unspecified.
