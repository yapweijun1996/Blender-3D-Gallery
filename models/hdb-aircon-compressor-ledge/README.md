# HDB Aircon Compressor Ledge

V2.1 item 308. A modular concrete aircon support ledge with wall upstand, diagonal steel supports, isolator rails and a simplified drain grating.

Independent source: `sources/hdb-aircon-compressor-ledge.blend`; reproducible generator: `generate.py`; optimized static glTF: `exports/optimized.glb`. Blender Z-up, glTF Y-up, metres. Source objects and materials remain individually editable. Studio camera/lights excluded from export.

Run Blender 4.0.2 `--background --threads 2 --python-exit-code 1 --python models/hdb-aircon-compressor-ledge/generate.py`. Use `-- --export-source --skip-render` to export saved source without regenerating. Run `node models/hdb-aircon-compressor-ledge/validate.mjs`, Blender `inspect_sources.py`, then `node models/hdb-aircon-compressor-ledge/verify_source_edit.mjs`. See verification.md for actual evidence and coverage.

Illustrative visual module only. No structural, security, fire, electrical or accessibility compliance is asserted. No deployment performed.
