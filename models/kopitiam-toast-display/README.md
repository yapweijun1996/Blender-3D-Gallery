# Kopitiam Toast Display

A compact two-level open toast display with six original stylized toast portions, steel trays and a timber frame.

V2.1 item 373. Metres; source +Z up/front -Y, GLB +Y up/front +Z. Ground datum at zero. All geometry/materials independently editable; no runtime operation or certification claimed.

Run Blender 4.0.2 background --python generate.py; --export-source --skip-render re-exports saved source without regeneration. inspect_sources.py writes edit fixtures and reports; run in isolated copy to preserve history. Then node validate.mjs and node verify_source_edit.mjs.
