# HDB Neighbourhood Shopfront

V2.1 backlog 317. Neighbourhood retail frontage module with replaceable blank sign panel, sheltered canopy, display glazing and an independently hinged entrance.

Blender 4.0.2: generate.py creates source and GLB. -- --export-source preserves manual source edits. render_views.py renders the shipped GLB; prepare_previews.py converts WebPs. Validate with node validate.mjs; inspect_source.py and node verify_source_edit.mjs verify actual source edits.

Metres; Blender +Z / glTF +Y up; Blender -Y / glTF +Z front. Original visual asset, no official brand or construction certification. Public redistribution terms unspecified; physical Android/iOS not tested.
