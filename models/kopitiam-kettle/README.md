# Kopitiam Kettle

A compact aluminium kopitiam kettle with a hollow body, rising open-bore spout, independent lift-off lid and insulated arch handle.

V2.1 item 370. Metres; source +Z up/front -Y, GLB +Y up/front +Z. Ground datum at zero. All geometry/materials independently editable; no runtime operation or certification claimed.

Run Blender 4.0.2 background --python generate.py; --export-source --skip-render re-exports saved source without regeneration. inspect_sources.py writes edit fixtures and reports; run in isolated copy to preserve history. Then node validate.mjs and node verify_source_edit.mjs.
