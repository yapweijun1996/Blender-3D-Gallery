# Mamak Roti Canai Griddle

A freestanding mamak roti canai griddle with a dark cooking plate, stainless chassis, backsplash, controls and lower shelf.

V2.1 item 374. Metres; source +Z up/front -Y, GLB +Y up/front +Z. Ground datum at zero. All geometry/materials independently editable; no runtime operation or certification claimed.

Run Blender 4.0.2 background --python generate.py; --export-source --skip-render re-exports saved source without regeneration. inspect_sources.py writes edit fixtures and reports; run in isolated copy to preserve history. Then node validate.mjs and node verify_source_edit.mjs.
