# Hawker Centre Ceiling Fan

V2.1 backlog 366. Three-blade ceiling fan with separate editable rotor, motor, downrod and ceiling canopy; static model only.

Blender 4.0.2: generate.py creates source and GLB; -- --export-source preserves manual edits. render_views.py renders the shipped GLB; prepare_previews.py produces WebPs. node validate.mjs validates geometry. inspect_source.py and node verify_source_edit.mjs prove actual source edits.

Metres; Blender +Z / glTF +Y up, Blender -Y / glTF +Z front. Static original asset, not a working appliance or certified food-contact item. Physical Android/iOS not tested; public redistribution terms unspecified.
