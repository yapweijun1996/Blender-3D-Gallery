# Motorcycle Parking Bay

V2.1 backlog 387. Open three-space motorcycle parking module with painted bay lines, wheel stops and a separate original two-wheel pictogram panel.

Blender4.0.2: `generate.py` creates source and GLB; `-- --export-source` preserves manual source edits. `render_views.py` renders the shipped GLB; `prepare_previews.py` converts WebP previews. Run `node validate.mjs`, Blender `inspect_source.py` and `node verify_source_edit.mjs` for structural and actual source-edit proofs.

Metres; Blender+Z/glTF+Y up, Blender-Y/glTF+Z front. Independent editable meshes/materials. Original illustrative asset, not official signage or engineering certification. No runtime interaction. See [verification](verification.md) for results and limits. Public redistribution terms unspecified; physical Android/iOS not tested.
