# Pomelo STEM

This collection contains the original Blender-built Pomelo STEM fruit mascot with a 20-joint rig, five clips, and a six-expression kit. The registered GLB includes `Idle`, `Wave`, `Blink`, `Cheer`, and `Jump`; a neutral stand is also included.

See [mascot/README.md](mascot/README.md) for reproduction, measured export values, animation notes, and remaining differences.
