# Marina Bay Sands construction loop

An architectural visualization of the original three hotel towers and the Sands SkyPark. The generated visual reference guided the palette, façade bands, waterfront plinth and cantilever silhouette. [Safdie Architects](https://www.safdiearchitects.com/projects/marina-bay-sands-hotel-and-skypark) documents the real building. The encoded construction sequence and dimensions are artistic approximations.

Regenerate the self-contained GLB from the repository root with `node models/marina-bay-sands-loop/build.mjs` after installing the repository dependencies. The GLB is authored directly in JavaScript with Three.js. It contains one 20-second animation and a completed static pose. The still poster shows the completed pose rendered from the GLB.

Open `?page=gallery&model=marina-bay-sands-loop` in the Gallery. The viewer repeats the clip when opened and provides a Play/Pause control. With reduced motion enabled, it opens on the completed still pose and plays on request.

The waterfront includes ten rising ArtScience Museum galleries around an open oculus. The GLB contains coated glazing, rippled pool and bay surfaces, and named construction stages. The Gallery adds live planar bay reflections. Museum proportions and construction timing are illustrative. [Museum architecture](https://www.safdiearchitects.com/projects/marina-bay-sands-artscience-museum)
