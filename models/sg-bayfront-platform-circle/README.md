# Bayfront MRT Circle line platform

Island platform with screen doors, seats and route maps in the Circle line colour.

- Tool: Blender 5.1.2 driven by GPT 6.2 (Codex).
- Source: Original model made for the Singapore open-world study; proportions follow public facts about the real place. No official endorsement.
- Verification: Khronos glTF validator 0 errors and 0 warnings; 7948 triangles; 888292 bytes.
- Map and place data in the open-world game come from OpenStreetMap contributors (ODbL).
