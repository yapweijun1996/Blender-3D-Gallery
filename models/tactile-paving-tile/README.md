# Tactile Paving Tile

A 300mm square ochre warning tile with 25 separately editable truncated-cone studs, made as an illustrative paving component.

V2.1 item 394, title-only scope. Generic original metric module, not surveyed or certified. No hydraulic, load, road, tactile/accessibility, drainage, engineering or regulatory compliance asserted. No fluid simulation or runtime interaction. Physical Android/iOS and WebKit NOT TESTED.

Metres; source +Z up/front -Y, GLB +Y up/front +Z. Ground/bottom datum zero.

Blender 4.0.2 --background --python generate.py; --export-source --skip-render exports saved source without regeneration. inspect_sources.py writes edit fixtures/reports; rerun isolated to preserve history. node validate.mjs and verify_source_edit.mjs.
