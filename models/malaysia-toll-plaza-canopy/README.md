# Malaysia Toll Plaza Canopy

A reusable two-lane toll-plaza canopy concept with six columns, three islands, teal fascia and two static lane indicators; no booths or payment system.

V2.1 item 384, title-only scope. Original regional-context interpretation, not surveyed or official design. Regional color treatments are illustrative choices, not claims of standard compliance. No engineering, road-sign, electrical, food, fire, wind, load or regulatory certification. Static lenses and lane indicators do not operate. Physical Android/iOS and WebKit NOT TESTED.

Metres; source +Z up/front -Y; GLB +Y up/front +Z. Ground datum zero. Components editable in source, no runtime operation.

Blender 4.0.2 --background --python generate.py; --export-source --skip-render reopens saved source without regenerating. inspect_sources.py writes edit fixtures/reports; rerun isolated to preserve evidence. node validate.mjs and node verify_source_edit.mjs verify GLB/source edits.
