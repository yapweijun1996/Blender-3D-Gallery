# Asset license decisions awaiting the owner

This is a decision checklist, not a license grant or legal opinion. No license, model, download link or publication permission is changed by this follow-up.

## Evidence and scope

- `models/eight-ball-billiards/README.md` describes original procedural geometry and no external textures; it explicitly leaves redistribution licensing undecided. Source authorship/rights still need owner confirmation.
- `models/solar-system/README.md` likewise leaves original geometry licensing undecided. Four retained map inputs have source-specific credits in `models/solar-system/reference/provenance.json` (Earth, Mars, Moon and Pluto). Those inputs and embedded derivatives cannot automatically be relicensed as original artwork.
- Website code, Blender/Python generators, geometry, GLBs, textures and screenshots are different deliverables; choose and record the intended scope instead of applying one ambiguous repository-wide label.

## Required owner decisions

1. **Rights holder and credit:** confirm who owns the original geometry/generators, whether any commissioned/contributor material exists, and the exact credited name/organization and URL.
2. **Reuse policy for original artwork:** allow commercial reuse and modification with attribution (a candidate is CC BY 4.0), require separate permission instead, or request another policy. Do not select a public license until ownership and intended permissions are confirmed. CC BY permits commercial sharing/adaptation and requires attribution; the grant should be reviewed before adoption: https://creativecommons.org/licenses/by/4.0/ and https://creativecommons.org/licenses/by/4.0/legalcode .
3. **Files covered:** decide separately whether the selected artwork terms include GLBs, editable `.blend`, baked original textures and renders/screenshots. Decide the software license for website and generator code separately.
4. **Third-party Solar maps:** retain each source's credits/terms and verify each source page before redistribution, especially commercial use. NASA's guidelines warn that third-party copyrighted material may be present; NASA branding/endorsement is a separate issue. Do not label the entire collection CC0 or NASA public domain merely because maps came from NASA-hosted pages. Official guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/ .
5. **Downloads while undecided:** choose whether to keep the existing download availability, temporarily disable it in a separately approved change, or add an explicit rights/permission notice. This follow-up does not alter existing downloads.

## Suggested decision reply

“Original rights holder: __; credit: __; original artwork reuse policy: __; covered file types: __; website/generator code license: __; Solar source-map review owner: __; existing downloads while pending: __.”

If the goal is broad reuse with credit, review CC BY 4.0 for the confirmed original artwork. If the goal is display only, retain a permission-based policy and define what viewers may download/use. These are alternatives for the owner, not automatically applied defaults.
