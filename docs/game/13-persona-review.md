# 13-persona review

Thirteen separately scoped, read-only reviewer sessions examined the changes from the perspectives below. They are AI reviews, not thirteen human specialists or thirteen independent proofs: sessions may share model-family blind spots. The primary agent checked accepted findings against source, real browser tests and screenshots. No numerical quality score is claimed.

| Reviewer | Confirmed finding / severity | Evidence, user impact and disposition |
| --- | --- | --- |
| Game Designer | No additional P0/P1/P2 confirmed. | Reviewed `rules.js`, `page.js` and [contract](gameplay-contract.md): actual groups, remaining balls and win/loss are retained. Rules and GLBs are unchanged. No complete match was personally played by this reviewer. |
| UI Designer | No additional P0/P1/P2 confirmed. | Inspected mobile/desktop baseline and Options screenshots plus `style.css`: hierarchy and palette remain consistent; no visible clipping in those images. Browser interaction and full contrast were not personally tested. |
| UX Researcher | P2: mobile drag-to-aim was hard to discover. **Fixed.** | `page.js` / `style.css` now expose a short instruction; the reviewer rechecked the [390px screenshot](../../output/playwright/game-audit/after/390-options-closed.png). This was a heuristic review, not a study with recruited users. |
| 3D Technical Artist | No additional P0/P1/P2 confirmed. | Inspected baseline and after screenshots, `scene.js` and asset provenance. Table framing, materials and lighting were retained; Performance can soften the image as disclosed. Pixel-equivalent and physical-device visual quality remain unverified. |
| Gameplay Engineer | P2: multi-pointer handoff and WebGL loss while paused obstructed recovery. **Fixed.** | `page.js` now transfers active pointer ownership and closes obstructing dialogs; the reviewer rechecked the tests. The primary agent executed the real-browser regressions. Physical touch cancellation remains unverified. |
| WebGL Engineer | P2: a paused dialog blocked context-loss recovery. **Fixed.** | `page.js` closes dialogs and focuses recovery; tests cover four dialog states and loading-time loss. The reviewer inspected code/tests, not GPU memory or a physical device. |
| Mobile Engineer | No additional P0/P1/P2 confirmed. | Reviewed pointer, resize and safe-area code and screenshots. Browser emulation exercises multiple sizes and viewport resizing; real orientation sensors, browser chrome and nonzero safe areas remain unverified. |
| Accessibility Engineer | P2: actual remaining ball numbers were absent from the narrow-screen accessibility tree. **Fixed for the tested tree; visible detail remains open.** | `page.js` supplies numbered accessible text without duplicate visual announcements; Chromium AX tests cover 320/390px. | QA Automation Engineer | P2: an early keyboard test could pass before an unintended asynchronous shot started. **Fixed.** | `scripts/test-game-browser.mjs` now counts the actual IndexedDB transaction and uses a transaction barrier before testing the focused-table shot. | Security Engineer | P2: malformed `data:` strings could be resolved as relative URLs. **Fixed.** | `scripts/catalog.mjs` checks core image/buffer URIs against Three.js resolution; negative fixtures cover malformed, relative and external values. The reviewer independently ran six catalog tests. Extension-defined resources and size limits remain outside this guard. |
| Product Manager | No additional P0/P1/P2 product defect confirmed. | Reviewed scope, real quality control, About navigation and [release readiness](release-readiness.md). Asset redistribution terms and device evidence are owner/release decisions, not proven complete by this review. |
| Performance Engineer | P2: Performance-mode ready times were initially easy to misread as measured after selection. **Corrected in report.** | [Performance report](performance-report.md) now labels them as default-quality startup times. The reviewer checked the source and raw JSON; three paired samples do not establish statistical significance or physical-device performance. |
| Creative Director | No additional P0/P1/P2 confirmed. | Inspected actual before/after desktop/mobile screenshots and `style.css`: the table, muted green palette and restrained controls remain visually coherent. Different mobile DPR/quality prevents pixel-identical comparison. |
