# Interface languages

Blender 3D Gallery starts in English (`en`). The language picker also offers 简体中文 (`zh-Hans`) and Bahasa Melayu (`ms`). The language button is available in the topbar and in the mobile Menu alongside Palette.

## Message source and rendering

[src/i18n/index.js](../src/i18n/index.js) owns language state and formatting. [English](../src/i18n/messages/en.js) defines the key set and supplies fallback text. English demo titles, descriptions, categories and search tags come from [data/demos.json](../data/demos.json). The dictionaries for [简体中文](../src/i18n/messages/zh-Hans.js) and [Bahasa Melayu](../src/i18n/messages/ms.js) provide the same keys. Demo IDs, slugs, query routes and filter values are stable across languages.

- Use `t("section.key", { name })` for computed text. The dictionary uses `{name}` for named substitution.
- Use `plural("section.count", count)` with `.one` and `.other` keys. It uses `Intl.PluralRules` and formats `{count}` with `Intl.NumberFormat`. A filtered count chooses the form using the total and supplies the matched count separately.
- In HTML, put `data-i18n="section.key"` on the element that owns the text. Use `data-i18n-aria-label`, `data-i18n-alt`, `data-i18n-title` and `data-i18n-placeholder` for accessible names and input hints. Wrap only the text when a control also contains a separate icon or input.
- Use `mountMarkup` for a view template and `localize(node, key, params, attr)` for generated controls and states. Bind to the existing element so a language change preserves input, focus and scene state. Use `onLanguageChange` when a derived view needs recomputing, such as a translated search result.
- Game v1 checkpoints and the service worker update protocol still carry their existing English status values. The active page translates those values when rendering the interface.

## Storage and first paint

The picker stores a validated locale ID in `localStorage` under `b3g:language:v1`. Missing, blocked or invalid storage uses English. The picker works in memory if a write is denied. A same-origin `storage` event applies changes from another tab, and clearing the preference restores English. The browser's language settings do not choose the gallery language.

[scripts/i18n-build.mjs](../scripts/i18n-build.mjs) fills the static HTML with English for the default and no-script render. It emits a parser-blocking head script with the same saved-locale reader as the runtime. The script sets `<html lang>` and the route title before body content, using a separate exact SHA-256 hash alongside Palette's hash in the production CSP. For saved Chinese and Malay, the render-blocking stylesheet hides the shell until its static and initial route copy is localized. Delayed demos then show a localized loading state while their chunks and models load.

The manifest keeps its existing app identity, launch URL, names and icons. Browser-owned installation prompts and system chrome follow the browser or OS.

## Adding a key or language

1. Add the key and matched placeholders in all three message files. Use the English wording and the glossary to choose the translation.
2. Reference the key from the template or call site. Keep translated markup out of dictionary strings and use text or attribute bindings for interpolation.
3. For a new language, add its BCP 47 ID and native display labels in [preferences.js](../src/i18n/preferences.js). Register its message table in [index.js](../src/i18n/index.js) and supply plural forms used by that language, with the same keys and placeholders in each table.
4. Run `node scripts/check-i18n.mjs` or `npm test`. The gate checks message parity, placeholders, known template keys and literal copy in the migrated markup and common DOM text assignments. Run `npm run build:deploy` to generate the revised CSP hash and verify small, medium and desktop layouts.

## Authored content

The 661 catalog records stay as curated English metadata. Model names, descriptions, tags, licences, credits, attribution and collection names retain their source wording. This includes reused product model text and source credits in Solar System. The library translates its category labels while retaining the original category values in URLs. Solar System uses translated celestial labels in its own controls. The Blender 3D Gallery name, GitHub, Three.js, source URLs and identifiers retain their original forms. In-model lettering, artwork, Product Studio label textures and user-entered shelf text are preserved. Low-level browser and WebGL diagnostics and the worker’s standalone HTTP 503 response keep their source text.
