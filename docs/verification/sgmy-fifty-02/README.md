# SG/MY modular library: second 50-asset batch

Adds exactly 50 new independent types: 360, 401–420 and 441–469. Latest tested base is `496b1dbc40cd0ac47c40524af4d06855f1d735a5`. Existing 194 catalog registrations (including four restricted GJH can variants) are preserved, producing 244 registrations. Registrations are not a claim that 244 master-backlog types are complete.

## Verified result
- All 50 local asset gates PASS; each release status remains **NEEDS REVIEW** for physical Android/iOS, Safari/WebKit and actual-device performance. Metadata remains draft. No deployment or main merge.
- 180,046 triangles / 10,182,716 GLB bytes across the 50 canonical exports; fixed per-asset complexity budgets retained.
- Independent editable Blender sources, original generators, optimized GLBs, multiangle previews, metadata, source-edit fixtures and validation evidence are included. Source proofs save/reopen a copied source with component and material edits, export without regeneration, and preserve the canonical source.
- 183 final studio views were inspected by producers (68 heritage + 51 services + 64 tropical), with additional corrected/open-pose views inspected. All 150 final producer browser initial views were inspected. Fresh integration produced **150/150 byte-identical initial screenshot matches** to those inspected final views, with exact final GLB consumption hashes. See `pixel-comparison.json`.
- 13 animated types / 18 GLB clips have exact track/pose/clearance checks. Fresh isolated browser animation checks cover ten assets (four heritage + six services); tropical's three moving props have structural/Mixer proofs and inspected Blender open poses. Gallery orbit/zoom exists; a Gallery animation-playback control UI is **not implemented**.
